# Руль — фронтенд Car Rental

Веб-интерфейс для посуточной аренды автомобилей. Исходники интерфейса находятся в `frontend/`.

## Локальный запуск

Требуется Node.js 20.19+ в ветке 20 или Node.js 22.12 и новее.


1. Запусти PostgreSQL и Spring Boot как обычно. По умолчанию прокси фронтенда обращается к `http://localhost:8080`.
2. В папке `frontend` выполни:

   ```bash
   npm ci
   npm run dev
   ```

3. Открой `http://127.0.0.1:3000`. Если сервер аренды выключен или автопарк пуст, открой `http://127.0.0.1:3000/?demo=1`. Демо работает на локальных примерах, бронь и отмена сохраняются до перезагрузки страницы.

Если Spring Boot работает по другому адресу, укажи его при запуске, например `CAR_RENTAL_API_URL=http://localhost:8081 npm run dev`.

## API

| Действие | Маршрут Spring Boot |
| --- | --- |
| Автопарк, цены и координаты | `GET /cars` |
| Регистрация и вход | `POST /auth/register`, `POST /auth/login` |
| Профиль | `GET /users/me` |
| Мои поездки | `GET /users/me/rentals` |
| Создание брони | `POST /rentals` |
| Отмена ожидающей брони | `POST /rentals/{id}/cancel` |

Поиск, сортировка и фильтр по классу работают по ответу каталога. «Рядом со мной» использует геолокацию браузера или координаты, введённые вручную. Координаты пользователя хранятся на странице. Фронтенд сортирует машины из каталога по расстоянию по прямой. Даты передаются в формате `LocalDateTime`, стоимость брони берётся из API. Токен хранится в `sessionStorage`. Подложка карты OpenStreetMap загружается из интернета. Иллюстрации привязаны к отдельным маркам и моделям, остальные машины отображаются с пиктограммой.

## Сборка

`npm run build` создаёт `dist/`. Команда `npm run preview` позволяет проверить сборку с тем же прокси. Чтобы раздавать `dist/` на другом сервере, настрой проксирование `/api` к Spring Boot со снятием префикса `/api` или задай `VITE_API_BASE_URL` перед сборкой и настрой CORS на стороне API.
